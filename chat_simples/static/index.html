Não chegou? Veja o que liberar no Android
  1. Notificações: Configurações → Apps → Chrome (e SalaVip, se instalou) → Notificações → permitir tudo, inclusive a categoria do site.
  2. Bateria: Configurações → Apps → Chrome → Bateria → Sem restrições. Faça o mesmo no app SalaVip.
  3. No Chrome: ⋮ → Configurações → Configurações do site → Notificações → chat.salavip.live permitido.
  4. Não deslize o app para fora dos recentes. Em muitos celulares isso força a parada do Chrome e nada chega até abrir de novo. Só aperte "voltar" ou "início".
  5. Xiaomi / Redmi / Poco: Configurações → Apps → Gerenciar apps → Chrome → Início automático ligado e Economia de bateria → Sem restrições. Nos recentes, puxe o card do app para baixo e toque no cadeado.
  6. Samsung: Configurações → Bateria → Limites de uso em segundo plano → Apps que nunca suspendem → adicione Chrome e SalaVip.
  7. Motorola / outros: Configurações → Apps → Chrome → Bateria → Sem restrições / "Permitir atividade em segundo plano".
  8. Confira se o Não perturbe está desligado.
